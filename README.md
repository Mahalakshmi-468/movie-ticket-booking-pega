# Movie Ticket Booking Management Application

Pega Platform project built for CineWave Entertainment as part of the National Internship Program (NIP), Pega Academy 2026.

## Overview
An application for managing movie ticket bookings, covering the full lifecycle from booking request to ticket confirmation.

## Case Type
Movie Ticket Request

## Case Lifecycle
1. Initial Request — customer submits Movie Name, Show Date, Show Time, Number of Tickets
2. Availability — seat availability checked, booking cost calculated
3. Approval — customer confirms or cancels the booking
4. Booking Execution — seats allocated, ticket generated, routed by show type
5. Resolved — booking completed, confirmation notification sent

## Built With
Pega Infinity (App Studio / Blueprint)
